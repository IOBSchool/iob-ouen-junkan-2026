## デプロイ手順（なつこさん／佳代子さん用）

1. Googleスプレッドシートを新規作成する（例：「応援の循環キックオフ_申込管理」）
2. そのシートで「拡張機能 → Apps Script」を開き、`gas_code.gs` の中身を全部貼り付ける
3. 「デプロイ → 新しいデプロイ → 種類：ウェブアプリ」
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
4. 発行された「ウェブアプリURL」をコピーする
5. `index.html` と `general.html` 両方の `const GAS_URL = "PASTE_GAS_WEBAPP_URL_HERE";` を書き換えて再デプロイする
6. Apps Script の「トリガー」画面で「時間主導型 → 特定の日時」を2つ設定する（既存生向け・一般向け両方のシートにまとめて送る）
   - `sendReminderDayBefore` … 10月1日（木）20:00頃
   - `sendReminderSameDay` … 10月2日（金）17:00頃
